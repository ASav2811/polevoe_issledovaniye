# Интерактивное полевое наблюдение — Балашихинский историко-художественный музей

Статический исследовательский лонгрид с 11 разделами, закреплённой навигацией, интерактивной музейной схемой и медиагалереями. Текст перенесён из авторского файла `текст для сайта дз1(1).docx` без содержательных изменений. Авторская коррекция: `20261110_113857.jpg` отнесён к экспозиции **«Салтыковка»**.

## Публикация через GitHub Pages

1. Создайте публичный репозиторий GitHub (например, `museum-observation`).
2. Распакуйте содержимое ZIP **в корень** репозитория. На верхнем уровне должен лежать `index.html`.
3. Откройте **Settings → Pages → Build and deployment → Deploy from a branch**, выберите `main`, папку `/ (root)`, сохраните.
4. После публикации откройте адрес Pages, показанный GitHub. В обычном случае это `https://ВАШ-ЛОГИН.github.io/ИМЯ-РЕПОЗИТОРИЯ/`.

## Структура проекта

- `index.html` — полный текст из финального DOCX и разметка 11 разделов;
- `style.css` — дизайн коллажа, левое меню и адаптивные стили;
- `script.js` — управление картой, навигацией и модальным просмотром;
- `media.js` — реальные файлы, распределённые по экспозициям;
- `media-plan.json` — описания источников и медиаплан;
- `assets/images/` — оптимизированные авторские снимки и утверждённое изображение карты;
- `assets/videos/` — оптимизированные видео;
- `Медиакаталог_уточнённый.csv` — полная таблица исходников и их назначений.

## Как добавить или заменить фото/видео

1. Скопируйте собственный файл в `assets/images/` (WebP/JPEG/PNG) или `assets/videos/` (MP4).
2. Найдите соответствующую экспозицию в `media.js` и добавьте запись типа `image` или `video`. В `src` должен быть **относительный путь** вроде `assets/images/мой-файл.webp`.
3. Для новой фотографии задайте короткую подпись в `caption`.
4. Загрузите изменённые файлы в репозиторий. Изменения опубликуются автоматически.

## Важное расхождение исходных материалов

В присланной **финальной версии DOCX** `20261110_113857.jpg` ещё встречается в подписи внутри раздела «Советский период». Автор отдельно уточнила, что реальная принадлежность файла — **«Салтыковка»**. На интерактивной карте и в `media.js` файл помещён только в галерею «Салтыковка». Сам исходный текст мы **не редактировали** — это расхождение оставлено для решения автором.

## Примечания

- Историческая планировка не придумана: коллажная карта использует оригинальную схему музея.
- В медиагалереях только фотографии/видео автора; декоративная карта — ранее сгенерированная по утверждённому макету.
- Шрифтовая система: **Oranienbaum, Jost**, каллиграфический акцент с предпочтением `Snell Roundhand` при наличии в системе. Google Fonts загружаются через сеть, но есть системные замены.
- Не забудьте проверить публичность репозитория: GitHub Pages делает сайт доступным другим пользователям по ссылке.
